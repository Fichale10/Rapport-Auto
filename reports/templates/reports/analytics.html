💡 Aide : « Croiser par » sélectionne des noms de champs (les colonnes du tableau) — les valeurs (régions, sites, causes…) s'affichent dans les lignes du tableau. Pour restreindre à une valeur précise (ex. Région = LOME), utilisez un Filtre ci-dessous. En savoir plus ▾
📘 Guide de l'exploration multi-niveaux

1. Croiser par (colonnes du tableau)
Choisissez 1 à 3 champs : chacun devient une colonne. Le tableau regroupe alors les incidents par combinaison de valeurs et affiche le nombre d'incidents et l'outage cumulé.
Exemple : champ 1 = Site, champ 2 = Technologies → une ligne par couple site / technologie.

2. Filtres (restreindre les données)
Chaque filtre = un champ + une valeur précise. Les filtres s'appliquent avant le croisement et se combinent entre eux (ET logique). La liste « Valeur » ne propose que les valeurs existantes, en tenant compte des autres filtres actifs.
Exemple : Filtre 1 : Région = LOME → seuls les incidents de LOME sont croisés.

3. Détail des incidents
Cliquez sur une ligne du tableau (ou sur « Afficher les incidents ») pour lister chaque incident avec tous les champs NetXcare renseignés : Site Parent, Plateforme, Alarm text, Root Cause, Ticket Number, technicien, observations…

Scénario type

  1. Filtre 1 : Région = LOME → les listes se limitent à cette région ;
  2. Croiser par : champ 1 = Site → tous les sites de LOME apparaissent ;
  3. Ajoutez champ 2 = Plateforme ou Alarm text pour affiner ;
  4. Cliquez sur une ligne pour le détail complet des incidents.

Remarque : la durée (Outage) est toujours calculée automatiquement — inutile de la choisir comme champ. Les champs proposés dépendent des colonnes présentes dans l'export NetXcare chargé.
